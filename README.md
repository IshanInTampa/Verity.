# Verity — Knowledge & Creation (expanded prototype)

Open `index.html` in a modern browser. No installation, API keys, AI services, or build tools required. Research needs internet access and some providers may restrict direct browser requests or `file://` origins. For best results, serve this folder on localhost with `python -m http.server 8000`, then visit http://localhost:8000.

## Included
- Responsive dashboard, light/dark mode, reduced-motion support
- Multi-source research: Wikipedia, OpenAlex, Crossref, Google Books, PubMed/Europe PMC; links to NASA, Smithsonian, USGS, Library of Congress, World Bank, NOAA, archives and licensed databases
- Multi-language code editor, local saves, imports/exports, sandboxed HTML preview, JSON validation
- Beginner coding academy with lessons, checks and local progress
- 2D CAD SVG geometry, snapping, dragging, properties, undo, save, SVG/JSON exports
- Grid-based house sketcher, save/export
- CSS animation editor with easing, presets, playback and export
- Canvas drawing with undo and PNG export
- Arithmetic parser (no `eval`), function graphing, PNG export
- Unit converter, crypto-based password generator, text analyzer, JSON formatter
- Notes and free/Pro membership concept

## Limitations
This is an expanded functional prototype, **not** an exhaustive knowledge engine or all-purpose production application. Search metadata is not a guarantee of truth. Licensed Gale/World Book/Britannica content is not copied or integrated without permission. No backend, real accounts, billing, secure entitlements, cloud storage, 3D CAD, STL, multi-file IDE, server-side language execution, or professional construction/engineering certification. Pro pricing and advanced features are proposals, not purchasable services. Local data can disappear when browser storage is cleared; export backups. Code preview uses a sandboxed iframe but should still be used only for code you trust. All features are non-AI.

## Production next steps
Secure backend and authentication, source adapters and caching, content licensing, privacy/security review, robust project storage, 3D geometry engine, language-specific runtimes, tests, accessibility audit, and adult-managed payment setup if subscriptions are introduced.

## Ultra expansion
- 3D Workshop: offline primitive mesh editor (box, cylinder, ellipsoid), orbit, zoom, dimensions, JSON import/export, ASCII STL export in millimeter convention. No Boolean operations or watertight guarantee for overlapping shapes; verify exported parts in a slicer before printing.
- Study Decks: local flashcards, reveal, repeat, JSON import/export. Not a scientifically calibrated spaced-repetition scheduler.
- Project Vault: local backup and restore for supported localStorage keys. Backups contain user data; store privately. Restore replaces matching saved projects.
- Command palette: Ctrl/Cmd+K to search tools; Esc to dismiss.

The website remains a local-first prototype. No real subscriptions, cloud accounts, general-purpose server code execution, professional CAD constraints, or copyrighted encyclopedia article licensing are included.
